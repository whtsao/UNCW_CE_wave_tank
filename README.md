# Overview
This repository contains numerical and physical modeling tools and workflows developed to study wave–structure and fluid–structure interactions using the wave flume at UNCW Coastal Engineering. Modules are developed for numerical simulation, laboratory testing, model calibration, verification, and validation, experimental–numerical comparison, data analysis, and post-processing. Topics include wave generation and propagation, interaction with coastal and marine structures, and comparison with laboratory measurements.  

# UNCW Coastal Engineering wave tank
The UNCW Coastal Engineering wave tank is an Edinburgh Designs wave flume designed for experimental studies of waves, coastal processes, and wave–structure interactions. The glass-and-steel tank is nearly 80 ft (24 m) long and 5 ft (1.5 m) wide, with a capacity of approximately 9,500 gallons (36,000 L) of water.
